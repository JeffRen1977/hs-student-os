# High School Student OS — 竞争力评估与功能建议（2026-10-28）

基于 `HIGH_SCHOOL_STUDENT_OS.md` 全文与 2026-10 竞品公开信息（价格为各公司官网/评测口径）。

## 结论先行

**有条件地有竞争力。** 你的差异化（跨域 Twin + 主动 Planner）是真的，但它是「系统级」优势，不是「功能级」优势：逐个功能对比，你每一面都打不过该领域的头部产品。所以这个产品只能以「多线作战的整合者」赢，不能以任何一个单点赢。赢的前提是跨域事件真的跑起来——在那之前（冷启动的头 1–2 个学期），它只是一个功能更少的 Fiveable + 更贵的 Kollegio。

目标客群必须收窄到：**同时打三条战线的学生**——10–11 年级、修 3 门以上 AP、要考 SAT、目标 Top 50。这群人（及其家长）付钱买的不是内容，是协调。单线用户留给 Khan（免费）和 Fiveable（$79/年全科）。

## 方案本身的三个结构性弱点

1. **护城河生效太慢。** 跨域事件的价值要 1–2 个学期的掌握度数据才复利；但用户流失发生在头两周。Phase 1 必须有一个不依赖跨域数据的即时爽点（见 P0 的诊断与模考）。
2. **内容规模不对称。** 5 门包对 42 门不是问题（你的客群修的就那几门热门课），问题是每门包的深度：MCQ 题量、模考、讲义。内容生产速度才是真瓶颈，方案里对这条轨的投入估算偏轻。
3. **没有分发设计。** 竞品各有渠道：Khan 靠学校/官方合作，Fiveable 靠教师端 + SEO，CollegeVine/Kollegio 靠大学端付费。方案里 Counselor 后台在 Phase 3，等于头一年没有获客引擎，只能靠家长口碑——这决定了增长曲线，不是功能问题，是生死问题。

## 建议新增功能（按优先级）

### P0 — 不补就没法卖
1. **全真模考引擎（SAT + AP）。** 定时、全长、Bluebook 式界面、模考后给出预测分与误差区间。你的「预测分」是全产品最核心的数字，没有全真模考锚定就没人信；Fiveable/UWorld/Khan 都有，这是入场券。目前方案只有练习与精批，没有模考。
2. **AP MCQ 练习引擎。** 按单元的 stimulus-based 选择题 + 逐题解析（Albert/UWorld 的主场）。FRQ 只占 AP 考试一半，缺 MCQ 等于缺一半产品。
3. **免费诊断入口（获客漏斗）。** 免费 SAT/AP 诊断测 + 免费选校定位，结果页给出「你的三条战线差距图」，转化到付费 OS。对标 Preptrak 的免费诊断、CollegeVine 的免费 chancing——没有免费入口就没有流量。
4. **家长端前置 + 付费闭环。** 家长才是付费方：把家长周报从 Phase 2 提到 Phase 1.5，并加家长视角的「值不值」页（提分轨迹 vs 目标校差距）。另加执行力机制：周计划完成率、连续学习、未完成任务自动重排并通知家长——问责恰是 Khan 的死穴（研究显示其 AI 辅导增量有限，学生不用起来），是你的楔子。
5. **Push 通道。** 主动 Planner 没有推送就是一句空话：先做 PWA + 通知（短信/邮件兜底），任务到期、模考周、截止日都走它。纯 Web 等学生打开的留存撑不起订阅。

### P1 — 决定客单价与续费
6. **奖学金与净价计算。** 选校矩阵加每校的预估净价与奖学金匹配（CollegeVine/Kollegio 都有）。对多数家庭，钱和录取同等重要；缺了它，申请模块只做了一半。
7. **截止日数据管线。** 方案说「不编造截止日期」是对的，但需要真管线：Common Data Set + 各校官网截止日的结构化采集与校验流程，否则动态矩阵没有可信输入。
8. **各校补充文书管理。** 12 年级真正的文书工作量是每校 2–5 篇 supplement，不是主文书一篇。加按校的 supplement 追踪 + 素材复用（从主线素材库切片改编），这是申请季的高频刚需，方案目前缺位。
9. **真人兜底层（混合模式）。** 纯 AI 的付费上限约 $25/月；加「真人终审」选项（ near-peer 导师或合作 IEC 做文书终读、选校复核）能把客单拉到数百至上千美元，也是信任背书。可先做按次付费，不养全职。
10. **日历自动导入。** Google Calendar / 学校日历导入自动建 Timeline，降低 Planner 的冷启动录入成本；`calendar.pressure` 的质量取决于这个。

### P2 — 期权与渠道
11. **PSAT/NMSQT 与 ACT 覆盖。** 不少学生双考；只做 SAT 会在一开始就筛掉一部分人。PSAT 与 SAT 共底，成本低，先行。
12. **教师/IEC 免费工具提前。** Fiveable 用教师端（免费布置+批改）反哺学生端获客。你的 Counselor 后台在 Phase 3 太晚了——哪怕先做一个「老师布置 FRQ、AI 预批」的免费小工具，都是渠道。
13. **把你的 Skill 做成 MCP 暴露给 ChatGPT/Claude。** Fiveable 已在做「进驻 AI app」。你的架构本来就是 MCP 注册制，顺势把 FRQ 精批做成可在 ChatGPT 内调用的入口，是低成本的新分发面。
14. **预测分可信度公开机制。** 长期记录并展示预测 vs 实际的校准曲线（先内部，后营销）。这是唯一能把「预测分」从文案变成资产的办法，也顺带满足不承诺录取的红线。

## 一句话战略

不要和 Khan 比免费、和 Fiveable 比科目数、和 Kollegio 比申请价格。对外只讲一件事：**「别家的 AI 只管一门课/一次考试/一份申请，我们管的是这三年里它们之间互相影响的每一次取舍。」** 然后用 P0 的模考与问责机制让用户在头两周就感受到这种取舍真的在发生。
